# Журнал

Журнал нужен, чтобы знания остались. Заметки пишутся в двух случаях: после каждой вехи (обязательно) и когда что-то наконец щёлкнуло (по желанию). Если не получается объяснить понятое в пяти предложениях, значит, оно ещё не понято.

Файлы:

- `veha-NN.md` — итоги вехи;
- `YYYY-MM-DD-тема.md` — заметки по ходу.

## Шаблон итогов вехи

```markdown
# Веха N: название

## Что сделано
Демо одной строкой и ссылка на него.

## Что понял
3–5 пунктов, каждый — мысль, которую раньше не знал.

## Что было сложнее всего
Где застрял и как выбрался.

## Где ошибся
Решения, которые пришлось переделывать, и почему.

## Что сделал бы иначе

## Цифры
Время на веху, p95, число пользователей — что уместно.
```
