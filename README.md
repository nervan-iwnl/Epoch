# Epoch

Платформа для алгоритмов, контестов, заданий в формате ШАД, курсов с домашками через git push, CTF и ML-соревнований. Один профиль и один рейтинг на всё.

Это пет-проект с двумя целями. Главная — прокачаться во всём программистском, кроме фронтенда: Linux и песочницы, базы данных, очереди и события, безопасность, Kubernetes, SRE. Вторая — если платформой начнут пользоваться, превратить её в сервис.
